# Cybersecurity Roadmap

## Glosario Técnico

### Virtualización

La virtualización es una tecnología que permite ejecutar varios sistemas operativos independientes sobre un mismo computador físico mediante un software especializado llamado hipervisor.

---

### Host OS

Es el sistema operativo principal instalado en el computador físico. Es el encargado de administrar los recursos del hardware sobre los que funcionarán las máquinas virtuales.

---

### Guest OS

Es el sistema operativo instalado dentro de una máquina virtual. Funciona de forma aislada del sistema operativo principal y utiliza los recursos asignados por el hipervisor.

---

### Hipervisor

Es el software encargado de crear, administrar y ejecutar máquinas virtuales. Controla el acceso al hardware y distribuye los recursos entre el sistema anfitrión y los sistemas invitados.

---

### Snapshot

Es una copia del estado completo de una máquina virtual en un momento determinado. Permite regresar rápidamente a ese estado si ocurre algún problema durante pruebas o configuraciones.
